# Aldy Imam Wijaya — Portfolio

Portfolio personal Aldy Imam Wijaya, Web Developer. Dibangun dengan React, TypeScript, Vite, dan Tailwind CSS.

## Fitur

- Tampilan responsif untuk desktop dan mobile
- Dark mode dan light mode
- Command palette dengan shortcut `Ctrl/Cmd + K`
- Daftar keahlian, proyek, dan kontak
- Download CV dalam format PDF

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka URL yang ditampilkan Vite di browser.

## Build dan verifikasi

```bash
npm run lint
npm run build
```

## Struktur penting

- `src/components/` — komponen UI
- `src/data/projects.ts` — data proyek
- `public/cv-aldy-imam-wijaya.pdf` — CV yang dapat diunduh
- `public/` — aset statis

## Teknologi

React · TypeScript · Vite · Tailwind CSS · CSS
